How to connect Google Sheets
One-time setup (5 minutes):
  1. Open Google Sheets → create a new spreadsheet
  2. Name the columns in row 1:
    Date, Amount, Category, Note, Person
  3. Open Extensions → Apps Script
  4. Replace all code with the script below and click Deploy → New deployment → Web App
  5. Set "Who has access" to Anyone → copy the URL → paste it above

Apps Script code to copy:

function doPost(e) { var sheet = SpreadsheetApp.getActiveSheet(); var d = JSON.parse(e.postData.contents); sheet.appendRow([d.date,d.amount,d.category,d.note,d.person]); return ContentService.createTextOutput("ok"); }
